Login Brute-Force Tester (mobil)

Nur für eigene Webseiten oder ausdrücklich genehmigte Tests. Sende Login-Versuche nur an Seiten, deren Eigentümer du bist oder für die du eine schriftliche Testerlaubnis hast.
Wichtig für die Funktion: Dies ist eine reine HTML/JS-Seite, die im Browser läuft. Browser blockieren aus Sicherheitsgründen (CORS) standardmäßig Anfragen an fremde Domains. Damit der Test funktioniert, lade diese Datei am besten auf deine eigene Webseite hoch (gleiche Domain wie das Login-Formular) und rufe sie von dort über dein Handy auf – dann greift CORS nicht.
Ziel
Erkennung
Text, der eindeutig bei Fehl- bzw. Erfolgs-Login in der Antwort erscheint.
Betriebsart
Passwortliste
PIN-Bereich
Probiert automatisch jede Zahl in diesem Bereich (max. 999999) als Passwort.
Tempo
0 = keine Pause zwischen den Anfragen eines einzelnen Workers.
Max. 20 gleichzeitige Anfragen – bewusst begrenzt, damit der Test deinen Server nicht in die Knie zwingt (kein DoS-Tool). Das entspricht dem üblichen Standardbereich regulärer Pentest-Tools.
