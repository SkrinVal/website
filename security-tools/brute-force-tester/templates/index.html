Login Brute-Force Tester

Nur fuer eigene Webseiten oder ausdruecklich genehmigte Tests. Das Tool sendet Login-Versuche an die angegebene URL. Wende es nur gegen Systeme an, deren Eigentuemer du bist oder fuer die du eine schriftliche Testerlaubnis hast. Maximal {{ max_attempts }} Versuche pro Lauf, maximal {{ max_concurrency }} gleichzeitige Anfragen.
